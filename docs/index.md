# WhoAmI registry

Every Harp device reports its device class as a `WhoAmI` identifier. Identifiers are reserved in the [harp-tech/whoami](https://github.com/harp-tech/whoami) repository by opening a pull request that adds the device to `whoami.yml`. The table below is generated automatically from that file.

The registry is published beside this page as plain files, so a code generator or an analysis script can read https://harp-tech.org/whoami/whoami.yml and validate it against the JSON schema at https://harp-tech.org/whoami/whoami.json.
